# PLOS ONE — Research Article — Submission Profile

**Fetched:** 2026-05-06
**Source of truth:** `journal_profile.yaml` (this file is the human-readable digest)

## Quick reference

| Item | Requirement |
|---|---|
| Word limit (main text) | None formal — typical 3,000–8,000 words |
| Abstract | ≤ 300 words, **unstructured**, single paragraph, no citations |
| Title | ≤ 250 characters, sentence case |
| Short title | ≤ 50 characters |
| Citation style | PLOS numbered (Vancouver-style), `[1]`, `[2,3]`, `[4-7]` |
| Reference format | `Author AB, Author CD. Title. Journal. Year;Vol(Issue): pages. doi:...` |
| Section order | Title → Authors → Abstract → Introduction → Methods → Results → Discussion → (Conclusions) → Acknowledgments → References → Figure legends → Tables → SI captions |
| Methods placement | Flexible — before Results, between Results and Discussion, or after Discussion |
| Figures | TIFF 300–600 dpi or EPS (vector). **No LaTeX-generated EPS.** Label as "Fig 1" |
| File format | DOCX/RTF/PDF on submission; LaTeX source on acceptance |
| Open access | CC-BY 4.0; APC applies |

## Mandatory statements

1. **Data Availability Statement** — repository name + DOI / accession / persistent identifier for every dataset.
2. **Funding Statement** — grant numbers and funder roles, or the verbatim sentence: *"The author(s) received no specific funding for this work."*
3. **Competing Interests** — full disclosure including patents and products in development.
4. **Author Contributions (CRediT)** — at least one CRediT role per author, entered in the submission system.
5. **Ethics Statement** (if applicable) — IRB / IACUC name + approval number; consent procedure for human subjects. **Required at submission since March 2023; absence = automatic rejection.**

## Editorial criteria

PLOS ONE evaluates **scientific validity and methodological rigor only** — not novelty, significance, or perceived impact. Replication studies, null results, and negative findings are explicitly in scope. ~20% of submissions are desk-rejected.

**Most common desk-rejection reasons:**
- Out of scope
- Obvious methodological flaws
- Missing Data Availability Statement
- Missing ethics approvals
- Language quality preventing review

## Reporting guidelines (apply where relevant)

| Study type | Guideline |
|---|---|
| Randomized trial | CONSORT |
| Systematic review / meta-analysis | PRISMA |
| Observational epidemiology | STROBE |
| Animal research | ARRIVE 2.0 |
| Diagnostic accuracy | STARD |
| Qualitative | SRQR / COREQ |

## AI use policy (summary)

- **AI tools cannot be authors.**
- Disclose AI use in a dedicated **Methods sub-section** (or Acknowledgments if no Methods section): tool name + version, how it was used, how outputs were validated, what was affected.
- Reviewers and editors must not upload submission content to generative AI platforms (confidentiality).

Full disclosure language and placement: see `ai_policy.md`.

## LaTeX template

- Official: https://journals.plos.org/plosone/s/latex

- **Do not** export figures as EPS from LaTeX — use Illustrator or Inkscape.
